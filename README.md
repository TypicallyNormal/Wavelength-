# Wavelength

> A little corner of the internet where I put things I make, experiment with, and enjoy.

**Wavelength v0.0**

Wavelength is my personal web space. A place for projects, games, experiments, art, music, photography, and whatever else I decide to build.

It's not meant to be a traditional portfolio or résumé.

It's more like a digital universe that grows with me.

---

## 🌊 What is Wavelength?

The idea behind Wavelength is simple:

**Everything I make, all in one place.**

The website will gradually grow into different spaces for different parts of my life:

- 🎮 **Games** — small games and experiments I build
- 🎨 **Art** — drawings, digital art, and design
- 💻 **Projects** — technical projects and experiments
- 📸 **Photography** — photos and visual archives
- 🎵 **Music** — music-related projects and recordings
- 🌐 **Socials** — places where you can find me online
- 🧪 **Experiments** — random ideas that don't fit anywhere else

Some things might be polished.

Some things might be completely stupid.

That's part of the point.

---

## 🚀 Version 0.0

Wavelength v0.0 is the starting point.

Currently, it contains:

- A basic landing page
- Animated sine wave
- Games section
- Projects section
- Art section
- Socials section
- Basic site structure

The website is intentionally simple for now.

This is the foundation everything else will grow from.
